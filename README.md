# Orange Builders - Residential Construction & Labour Contracts Website

Production-ready, highly-responsive, modern construction company website for **Orange Builders**, based in Madurai, Tamil Nadu, India.

---

## 🏗️ Project Overview

Orange Builders is a trusted residential house construction and labour contract firm led by **Er. Nowsadh**. This website establishes online trust, showcases completed & ongoing construction projects, provides educational construction tips, offers English & Tamil (EN/TA) language toggling, and drives high-converting leads through interactive forms and floating WhatsApp integration.

---

## ⚡ Key Features

- **Modern Corporate Construction Aesthetics**: Logo Orange primary theme, Dark Charcoal secondary, Warm White neutral accent, and sleek glassmorphism panels.
- **Dark & Light Mode Switcher**: Circular floating theme switcher with `localStorage` persistence.
- **Dual-Language i18n Support**: Instant English (EN) & Tamil (TA) translation switcher.
- **Interactive Project Showcase**: Filterable portfolio (Ongoing, Completed, Labour Contract, Residential) with detail modal lightboxes.
- **8-Stage Construction Process Timeline**: Detailed step-by-step roadmap from foundation to handover with quality checklists.
- **SEO-Optimized Construction Tips (Blog)**: Technical articles with category filtering and search.
- **High-Converting Lead Form**: Built with `React Hook Form` + `Zod` validation and celebratory confetti feedback.
- **Floating Utilities**: Direct WhatsApp chat button with prefilled project enquiry message.

---

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org/) 16 (App Router)
- **Library**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Custom CSS Variables
- **Animations**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React
- **Form Handling**: React Hook Form, Zod Validation

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm or pnpm or yarn

### Installation & Local Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ManiprabhuG/OrangeBuilder.git
   cd OrangeBuilder
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build & Production Verification

To build and compile the application for production deployment:

```bash
npm run build
npm run start
```

## 🎯 SEO & Technical Optimizations

- **Meta Tags**: Custom Page Titles, Descriptions, Canonical URLs, and OpenGraph/Twitter Cards on all routes.
- **Structured Data (JSON-LD)**: `HomeAndConstructionBusiness` schema markup on root layout.
- **Sitemap & Robots**: Auto-generated dynamic XML sitemap (`/sitemap.xml`) and robots.txt (`/robots.txt`).

---

## ☁️ Deployment Guide (Vercel)

This application is ready for zero-config deployment on Vercel:

1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "Initial production-ready Orange Builders website"
   git push origin main
   ```
2. Connect your GitHub repository to [Vercel](https://vercel.com).
3. Select **Next.js** framework preset.
4. Click **Deploy**.
